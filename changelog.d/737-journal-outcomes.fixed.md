- **The journal records closed issues and the repo of every merge.** A pull request merged or opened with `gh pr --repo owner/name` is now filed under the local checkout whose `origin` is that repo, where before it named no repo. `gh issue close N` is a new `issue` entry, and a merged pull request adds one for each `Closes #N`, `Fixes #N` or `Resolves #N` in the body its `gh pr create` passed. The journal rebuilds itself once on upgrade, so history gains these entries.
