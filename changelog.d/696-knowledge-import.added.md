- **Moving skills and memories in.** The `/setup` agent can move the skill folders, auto-memory files and procedure docs you tick into aegis with `knowledge_import`. Each is read as your own user, copied whole with its scripts and binaries (20 MiB at most per folder), saved approved as one commit, and a name aegis already holds is refused rather than overwritten. One card lists what came in, with an Undo per item. Your setup record keeps what was imported, so a later `/setup` proposes only what is new.
