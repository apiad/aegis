This folder holds `ledger`, a small Python tool that reads bank CSV exports and reports income and spending by month, spending by category, and one month's spending against a budget. Its test suite is failing. Find out why and fix the code so `python3 -m pytest` passes. Do not change the tests. Then check the tool against the sample files with `python3 -m ledger.cli report sample.csv`, `python3 -m ledger.cli categories sample.csv --since 2026-01-01` and `python3 -m ledger.cli budget sample.csv limits.csv --month 2026-01`, and make sure the figures add up.
