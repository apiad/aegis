# send_file Implementation Plan

**Status: done, 2026-10-06.** Executed inline; every task below landed on `feat/send-file`.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An agent calls `file_send(path, caption?)`; the file is copied into the server's state, appears in the transcript with a preview, Open and Download, and is served by aegis at an unguessable URL.

**Architecture:** A new module `src/aegis/files.py` owns classification, the copy and the response headers. The session records a `file` store record; `Fold._own` turns it into a `file` entry. `agent_ops.py` registers `file.send`; `web.py` adds `GET /files/{file_id}/{name}`. The client gains a `file` renderer.

**Tech Stack:** Python 3.13, Starlette, pydantic, vanilla JS modules, pytest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-06-send-file-design.md`

## Global Constraints

- Size limit 100 MB: `MAX_BYTES = 100 * 1024 * 1024`, a module constant tests lower.
- File id: `secrets.token_urlsafe(16)` (128 bits).
- Storage path: `<state_root>/files/<id>/<name>`, written to a temp name and renamed.
- Excerpt: `markdown` and `text` only; first 40 lines or 4096 bytes, whichever is shorter, cut at a line boundary.
- Preview kinds, exactly: `image`, `pdf`, `html`, `markdown`, `text`, `audio`, `video`, `other`.
- Every response: `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `Cache-Control: private, max-age=31536000, immutable`.
- `Content-Security-Policy: sandbox` on `html`, SVG and any XML type; never on PDF.
- Operation name `file.send`; MCP tool `file_send`; agents only.
- Tool result: `{url, name, size, mime}`, `url` relative: `/files/<id>/<name>`.

## Review Focus

1. A file name with spaces, `#`, `?` or non-ASCII (`informe año.pdf`): the URL must be percent-encoded and the route must still match. Test in Task 4.
2. A binary file with a text-looking extension or no extension (`data`, `blob.bin`): must not be stored with a garbled excerpt. Test in Task 1.
3. An HTML file opened with Open must not read the client's `sessionStorage`: the sandbox header is the guard. Test in Task 4 (header) and Task 5 (iframe `sandbox`).
4. A relative path from an agent whose cwd is not the server root: resolves against the session's cwd. Test in Task 3.
5. Two files with the same name sent twice: two distinct entries and URLs, the first not overwritten. Test in Task 3.

### Task 1: `files.py`, classify and store

**Files:**
- Create: `src/aegis/files.py`
- Test: `tests/test_files.py`

**Interfaces:**
- Produces: `classify(path: Path) -> tuple[str, str]` (mime, preview); `excerpt(path: Path) -> str | None`; `store(state_root: Path, src: Path) -> dict` returning the store record body `{"kind": "file", "file_id", "name", "mime", "size", "preview", "excerpt"}` (no caption); `find(state_root: Path, file_id: str, name: str) -> Path | None`; `headers(path: Path, download: bool) -> dict[str, str]`; `url(file_id, name) -> str`; `MAX_BYTES`; `FileError(code, message)`.

- [x] **Step 1: failing tests** for: each preview kind by extension (`a.png`→image, `a.svg`→image with `image/svg+xml`, `a.pdf`, `a.html`, `a.md`, `a.py`→text, `a.csv`→text, `a.mp3`→audio, `a.mp4`→video, `a.zip`→other); an extensionless UTF-8 file → text; an extensionless file with a NUL byte → other with no excerpt; excerpt cut at 40 lines and at 4096 bytes on a line boundary; `store` copies (deleting the source keeps the copy), refuses a directory (`not_a_file`) and a file over a lowered `MAX_BYTES` (`too_large`); two stores of the same name give two ids; `find` returns `None` for a wrong name or unknown id and rejects ids with `/` or `..`; `url("x", "informe año.pdf") == "/files/x/informe%20a%C3%B1o.pdf"`.
- [x] **Step 2:** `uv run pytest -q tests/test_files.py` fails (no module).
- [x] **Step 3: implement.** `mimetypes.guess_type`; empty or `application/octet-stream` → sniff 4 KB (NUL → binary; `decode("utf-8")` ok → `text/plain`). Map: `image/*`→image, `application/pdf`→pdf, `text/html`→html, `.md/.markdown` or `text/markdown`→markdown, `text/*`, json, yaml, xml, javascript, toml and the sniffed text → text, `audio/*`, `video/*`, else other. Copy with `shutil.copyfile` to `<dir>/.<name>.part` then `os.replace`. `headers`: download → `attachment; filename*=UTF-8''<quoted>`; else markdown/text → `text/plain; charset=utf-8`; other → attachment; html, SVG, any `xml` mime → add `Content-Security-Policy: sandbox`; always the three common headers.
- [x] **Step 4:** tests pass.
- [x] **Step 5:** commit `feat(files): classify, copy and serve headers for sent files`.
