FILES AND NAMES
- Pages: src/aegis/help/<id>.md  (data only: no __init__.py in that directory; the wheel already ships every file under src/aegis).
- src/aegis/helppages.py  (slice 1): pure, no app imports.
    HELP_DIR: Path = Path(__file__).parent / "help"
    KINDS = ("concept", "howto", "tutorial")
    @dataclass(frozen=True) Section(page: str, slug: str, heading: str, text: str)
    @dataclass(frozen=True) Page(id: str, title: str, kind: str, when: str, body: str, sections: tuple[Section, ...])
        sections[0] is the text before the first "## " heading, slug "" ; every later one is a "## " heading.
    def slug(heading: str) -> str            # lowercase, non [a-z0-9] runs -> "-", stripped of "-"
    def parse(id: str, text: str) -> Page    # raises ValueError naming the file when title/kind/when is missing or kind unknown
    def load(dir: Path = HELP_DIR) -> list[Page]   # sorted by id
    @dataclass(frozen=True) Hit(ref: str, heading: str, when: str, snippet: str)   # ref = "page#slug" or "page" for sections[0]
    class Index:
        def __init__(self, pages: list[Page]) -> None
        pages: dict[str, Page]
        def search(self, query: str, limit: int = 5) -> list[Hit]   # BM25 over sections; title x3, when x2
        def read(self, page: str, section: str | None = None) -> str  # raises KeyError(msg) where msg names the 3 closest page ids
        def listing(self) -> list[dict]   # [{"id","title","kind","when"}], sorted by kind order KINDS then title
- src/aegis/help_ops.py: def register(r: Registry, app) -> None, called where the other *_ops modules are registered.
    slice 1: help.search (agent=True, read=True)  params: query: str (min 1), limit: int = 5 (1..20)
             -> {"hits": [Hit as dict...]} ; with no hits -> {"hits": [], "pages": index.listing()}
             help.read   (agent=True, read=True)  params: page: str, section: str | None = None -> markdown str ; unknown -> OpError("unknown_page", msg)
    slice 2: help.pages  (client only)  -> index.listing()
    slice 3: help.state  (client only)  -> {"tutorial": bool, "whats_new": str | None}  (whats_new = installed version to offer, or None)
             help.dismiss (client only) params: what: Literal["tutorial", "whats_new"] -> "noted"
             help.guide  (client only) params: kind: Literal["tutorial", "whats_new"], page: str | None = None,
                         agent/harness/model/effort/permission/cwd: str | None = None (the same fields session.spawn takes)
                         -> {"log_id": str, "handle": str}
- src/aegis/helpstate.py (slice 3): the per-principal record <state_root>/help/<principal>.json = {"tutorial": bool, "toured": str | None}
    class HelpState: def __init__(self, dir: Path); def get(self, principal: str, *, owns_sessions: bool, installed: str) -> dict;
                     def mark_tutorial(self, principal: str) -> None; def mark_toured(self, principal: str, version: str) -> None
    write-then-rename like meta.py.

    def sections_between(text: str, after: str | None, upto: str) -> str   # "## [x.y.z]" sections with after < v <= upto; [Unreleased] never; after None -> upto only

PAGE WRITING RULES (slice 1 writes them; every slice follows them)
- frontmatter: title, kind (concept|howto|tutorial), when (one line).
- agent tools in backticks as tool names (`monitor_start`); aegis commands as `/name`; harness commands in plain text, never backticked;
  CLI as `aegis link add`; repo paths in backticks only on authoring pages.
- First pages (slice 1): getting-started (tutorial), sessions, monitors, queues, handoffs, artifacts, links, config, commands, writing-help-pages.
  Slices 2-4 update `commands` and add sections for what they ship (Help tab in getting-started / sessions; /tutorial and /whats-new in commands).
