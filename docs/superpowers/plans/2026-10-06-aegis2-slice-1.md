# aegis2 slice 1 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Status: in progress, 2026-10-06.** Executed inline by the session that wrote it,
at Alex's request ("plan and implement to the end, then let me smoke drive it").

**Goal:** `aegis2 serve` runs one Claude Code session that Alex drives from a
browser tab, usable for real work in one repo.

**Architecture:** One Starlette process serves a static ES-module client and one
websocket. An operation registry answers `call` messages; state reaches the
browser as channels (snapshot, then numbered patches). One `claude -p` child per
session; its stdout lines are stored raw and folded into entries whose facts are
decided in Python and drawn by the browser.

**Tech Stack:** Python 3.13, Starlette, uvicorn, pydantic, typer (all already in
`pyproject.toml`); plain ES modules; vendored markdown-it; Playwright for browser
tests and the bench (dev group).

**Spec:** `docs/superpowers/specs/2026-10-06-aegis2-slice-1-design.md`

## Global Constraints

- No file under `src/aegis2/` imports `aegis`; imports inside aegis2 are relative.
- Nothing under `src/aegis2/` calls `Path.cwd()` or `os.getcwd()` except `cli.py`.
- The store is `<state_root>/transcripts/<log_id>.jsonl`; `log_id` is minted at spawn.
- State root is `<config_root>/.aegis2/state`; default port 8742; default host 127.0.0.1.
- Protocol version `1`; `hello` within 5 s; `Origin` must be `http://<Host>` and `Host` must be loopback or the bound host.
- Markdown renders with `html: false`.
- Claude argv: `-p --input-format stream-json --output-format stream-json --replay-user-messages --verbose --model M --effort E --permission-mode P --strict-mcp-config --mcp-config {"mcpServers":{}}`.
- Permission vocabulary is the old one: read → plan, write → acceptEdits, full → bypassPermissions, auto → auto. Effort: low, medium, high, max.
- Interrupt timeout 10 s. SIGTERM then SIGKILL after 5 s on close.
- Bench reports, never gates; CI warns past 20% worse.

## Review Focus

1. A prompt sent mid-turn: status stays `working`, both prompts echo in order, one `result` returns to idle. Tested in Task 5 with the fake's `/sleep` script.
2. A page reload mid-turn: the snapshot equals what the live patches built. Tested in Task 5 (live entries equal a re-fold of the store) and Task 8 (reload in the browser).
3. A 2 MB tool result on one stdout line: parsed, stored, and its entry carries only the tail. Tested in Task 5 with the fake's `/big` script.
4. Claude not on PATH, or a cwd outside the config root: spawn replies an error code and no session is left behind. Tested in Task 6.
5. A second browser tab on the same server: both see the same patches. Tested in Task 6 with two websocket clients.

### Task 2: The stream parser

**Files:** Create `src/aegis2/claude/__init__.py`, `src/aegis2/claude/stream.py`; Test `tests/aegis2/test_stream.py`

**Interfaces:**
- Produces: `parse(line: str) -> list[Event]` where `Event` is one of
  `Init(session_id, model, version)`, `Text(text, parent, usage)`,
  `Thinking(text, parent, usage)`, `ToolCall(id, name, input, parent, usage)`,
  `ToolOutput(id, text, is_error, parent)`, `Echo(text)`,
  `Result(is_error, subtype, duration_ms, cost_usd, stop_reason, context_window)`,
  `Notice(subtype)`, `Compact(pre_tokens, post_tokens)`, `Ignored(type)`,
  `Garbled(raw)`. `usage` is `Usage(input, cache_creation, cache_read, output)` or None;
  `TURN_BEARING = (Text, Thinking, ToolCall, ToolOutput)`.

One assistant line can carry several blocks; `parse` returns all of them. An echo is
a `user` line with `isReplay: true`. `context_window` is read from
`modelUsage[*].contextWindow` (Claude Code 2.1.283 reports it). Valid JSON of an
unhandled type is `Ignored`; anything else unparseable is `Garbled`.

- [ ] Tests from real line shapes (copied from the probe): init, text, thinking, a two-block assistant line, tool_use, tool_result list content, echo, result with `modelUsage`, `thinking_tokens`, `hook_started`, `compact_boundary`, `rate_limit_event` (Ignored), `not json` (Garbled), `[1,2]` (Garbled).
- [ ] Implement, run, commit.

### Task 3: Store and fold

**Files:** Create `src/aegis2/transcript/__init__.py`, `store.py`, `entries.py`, `describe.py`; Test `tests/aegis2/test_store.py`, `tests/aegis2/test_fold.py`

**Interfaces:**
- `Store(path)`: `append(record: dict) -> int` (index of the record), `path`;
  `read_store(path) -> tuple[list[dict], int]` (records, damaged count).
- Records: `{"ts", "src": "claude", "line": "<raw stdout line>"}` and
  `{"ts", "src": "aegis2", "kind": "spawn"|"send"|"exit"|"interrupt_timeout"|"close", …}`.
- `Fold()`: `apply(index: int, record: dict, events: list[Event] | None = None) -> list[dict]`
  returning patch ops `{"upsert": entry}` / `{"remove": id}`; `entries() -> list[dict]`;
  `fold_records(records) -> Fold`.
- `describe.py`: copied from `src/aegis/render_shared.py`: `tool_label`, `result_digest`,
  `diff_window`, `diff_counts`, `format_tool_args`, `tool_glyph`, `result_line`.

Entry rules: echo → `user` `e<i>`; send → `pending:<i>`, removed by the next echo
in send order; text → `prose`; thinking → `thinking`; tool call → `tool` keyed by
its id, `running`; tool output upserts it `ok`/`err` with `detail.result`,
`detail.tail` (last 40 lines, capped at 8 KB), `detail.collapsed = not is_error`,
`detail.args`, `detail.diff` for Edit/Write; a subagent event (`parent` set) makes
no entry and increments `detail.steps` on its parent; `result` → `system` line
"done in 3.2s · $0.04" or `error` "interrupted"; `compact_boundary` → `system`;
init → `system` "Claude Code 2.1.283 · claude-opus-…" (first only); spawn → `system`;
exit → `error` with code and stderr tail; garbled → `system` with the first 200
characters; notices and ignored lines → nothing.

- [ ] `test_store.py`: append returns 0, 1, 2; a hand-written damaged line in the middle is skipped and counted; a truncated last line is skipped.
- [ ] `test_fold.py`: echo, not send, creates the user entry; two sends then two echoes keep order and remove both pendings; a notice yields no op; tool call then output replaces the same id; an error output starts uncollapsed; Edit carries a diff window; subagent steps; re-folding the same records gives identical entries (the determinism lesson).
- [ ] Implement, run, commit.

### Task 5: The Claude process, the session, and a fake claude

**Files:** Create `src/aegis2/claude/process.py`, `src/aegis2/session.py`, `tests/aegis2/fake_claude.py`; Test `tests/aegis2/test_session.py`

**Interfaces:**
- `build_argv(claude_bin, model, effort, permission) -> list[str]`.
- `ClaudeProcess(argv, cwd, stderr_path, on_line, on_exit)`: `start()`, `write(obj)`, `terminate()`, `pid`.
- `SpawnSpec(profile, model, effort, permission, cwd: Path)`.
- `Session(log_id, spec, store, claude_bin, publish, interrupt_timeout=10.0)`:
  `start()`, `send(text)`, `interrupt()`, `close()`, `meta() -> dict`, `entries() -> list[dict]`;
  `publish(channel: str, ops: list[dict])`.
- The fake reads stdin JSON lines. A user message echoes, then runs a script picked
  by the text: `/sleep N` (Bash call, sleep, output, text, result), `/fail` (Bash
  call with an error output), `/notice` (three system notices, no result),
  `/big` (a 2 MB tool output on one line), `/exit N` (stderr lines, exit N),
  `/deaf` (ignore the next interrupt); anything else answers with text and a
  result. An interrupt `control_request` ends the running script with an error
  result. `FAKE_CLAUDE_REPLAY=<store file>` replays its claude lines on the first
  prompt instead, with `FAKE_CLAUDE_EMIT_LOG=<file>` recording each tool call's
  emit time for the bench.

- [ ] Tests (async, fake as `claude_bin` via `sys.executable` wrapper script): idle → working on send → idle on result; `/notice` while idle never sets working; a send during `/sleep 1` gives two echoes in order and one result; interrupt mid-`/sleep 5` yields an error result and idle; `/deaf` then interrupt with `interrupt_timeout=0.5` sets error and an error entry; `/exit 3` sets error with stderr tail in the entry; `/big` stores and folds with a tail ≤ 8 KB; after every scenario the live entries equal `fold_records(read_store(path)).entries()`; the store file name is the log id; close terminates the child.
- [ ] Implement, run, commit.
