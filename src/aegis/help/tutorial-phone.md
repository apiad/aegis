This tutorial puts aegis on a phone and uses it the way a phone is used:
installed, sometimes offline, with notifications. Open aegis in Chrome on the
phone over https, signed in with your token: installing, working offline and
push all need https. The phone page holds the details.

## 1. Install it

On the Fleet, the install card offers Install when the browser allows it;
Settings, under This browser, has the same button. Press it and follow the
three rows: the download, the browser's confirmation, notifications. You
should see aegis on the home screen, opening without the browser's bars.

## 2. Turn on push

Press the bell and choose what this device hears about: needs you, errors,
something to read, finished work, toasts. Press Send a test. You should see a
notification arrive. Tapping it opens aegis.

## 3. Write while offline

This step spends quota once the connection returns.

Open a session on the phone, then turn on airplane mode and write a
message in it. You should see a
banner saying the connection is down, and your message after the last row,
marked queued. Turn the connection back on: the message goes out by itself
if nothing happened in the session since you wrote it.

## 4. Read a docked page as a tab

This step spends quota.

Ask a session "Send me the README with file_send, docked on the right." You
should see a strip of tabs under the header, the transcript's first, and the
file in a tab of its own. Press and hold the file's tab for half a second to
get Undock.
